# اتوکلیکر اندروید

کلیک خودکار با دقت میلی‌ثانیه، زمان‌بندی شروع، ساعت مرجع قابل انتخاب (سایت بورس یا NTP)، نوار شناور پلی/استاپ و تم تاریک.

## امکانات
- فاصله‌ی بین کلیک‌ها به میلی‌ثانیه
- تعداد ضربه (دستی با + و −، صفر = بی‌نهایت)
- شروع زمان‌بندی‌شده (ساعت:دقیقه:ثانیه.میلی‌ثانیه)
- دو منبع ساعت مرجع، با آدرس قابل تغییر:
  - سایت (پیش‌فرض tsetmc.com): ساعت از هدر Date سرور خوانده می‌شود و با چند درخواست پشت‌سرهم به دقت میلی‌ثانیه می‌رسد
  - NTP (پیش‌فرض time.google.com)
- پیش‌دستی (جبران تأخیر) به میلی‌ثانیه
- نوار شناور (▶ / ■ / ✕) و دایره‌ی هدف قابل جابه‌جایی

## بیلد
- گیت‌هاب: تب Actions → Build APK → فایل `AutoClicker-debug` را از Artifacts دانلود کن.
- یا Android Studio: Build > Build APK. (Gradle 8.2 یا بالاتر، JDK 17)

## استفاده
1. APK را نصب کن و سرویس دسترسی را روشن کن.
2. منبع ساعت را انتخاب کن (سایت یا NTP) و «همگام‌سازی ساعت» را بزن.
3. تنظیمات را وارد کن و «نمایش نوار شناور و هدف» را بزن.
4. دایره‌ی قرمز را روی نقطه‌ی مورد نظر ببر و ▶ را بزن.

## نکته‌ها
- ساعت سایت دقت تقریبی ده‌ها میلی‌ثانیه دارد (عدد ± بعد از همگام‌سازی نمایش داده می‌شود). NTP معمولاً دقیق‌تر است.
- ساعت سایت، ساعت سرور وب آن سایت است و لزوماً ساعت موتور معاملات نیست.
- اگر تا شروع بیش از ۱۵ ثانیه مانده باشد، برنامه قبل از انتظار یک بار دیگر ساعت را همگام می‌کند.
- اگر زمان تنظیم‌شده گذشته باشد، برای فردا زمان‌بندی می‌شود.
